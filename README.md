# 🚀 아기 언어 번역기

> 하드웨어에서 수신한 아기 울음 데이터를 던스턴 베이비 랭귀지 기준으로 번역하는 Flutter 앱입니다.

<!-- 대표 이미지나 시연 GIF가 있다면 여기에 넣어주세요. -->

<br>

## 📖 프로젝트 소개

- **프로젝트**: 아기 울음 번역기
- **소개**: `neh`, `owh`, `heh`, `eairh`, `eh` 울음 유형을 보호자가 이해하기 쉬운 원인과 대처 방법으로 보여줍니다.

<br>

## ✨ 주요 기능

| 기능 | 설명 |
| :-- | :-- |
| 울음 번역 | 5가지 울음 유형별 원인과 대처 방법 표시 |
| JSON 시뮬레이션 | 하드웨어 수신을 대신해 테스트 버튼으로 결과 확인 |

<br>

## 🛠 기술 스택

- **프레임워크 / 라이브러리**: Flutter, Material 3
- **도구**: JSON 데이터 파싱

## 🤝 협업 규칙

- **브랜치**
  - `develop`: 개발용 기본 브랜치. 모든 작업은 여기서 시작해요.
  - `feat/기능이름`, `fix/버그이름`: `develop`에서 만들어서 작업하고, PR로 `develop`에 합쳐요.
  - `main`: 발표나 배포할 때만 `develop`을 합쳐요.
- **커밋 메시지**: `feat: 로그인 기능 추가`, `fix: 버튼 클릭 오류 수정`, `docs: README 수정`
